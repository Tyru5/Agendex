# Cross-agent comparison and handoff

Open a plan and expand **Compare across agents and hand off**. **Find related plans from other agents** checks up to twenty recently updated plans in the exact same workspace (and the same cloud owner). Matching requires substantial content overlap, two shared file references with supporting terms, or an explicit shared work reference (`issueUrl`, `pullRequestUrl`, `workItemId`). Each suggestion explains its evidence and opens the existing comparison view. Suggestions are approximate and never change session lineage or receipt provenance. Plans without a workspace are not matched.

Cloud summaries are hydrated on request through the existing authenticated plan-content query, with at most four requests in flight. Missing or inaccessible content is skipped and reported. The candidate limit means older relevant plans may not be suggested; the normal compare picker remains available.

Download the handoff Markdown, review it, and save it on the machine where the target CLI will run. Detect installed CLIs through the connected local API, enter the downloaded file's absolute path, then prepare and copy the command. Commands target a POSIX shell and a local absolute workspace. Codex and Claude Code are supported using their interactive positional prompt argument, verified against the installed `codex --help` and `claude --help`; Agendex does not infer source session IDs, resume sessions, launch a process, bypass permissions, or alter CLI settings. Windows command preparation is unavailable. Other source agents still support Markdown export.

Cloud-only clients can export context; detecting installed CLIs needs a reachable local Agendex API. Workspace paths synced from another computer must be reviewed before running a command. Newlines/control characters in command paths are rejected; shell metacharacters and apostrophes are quoted.
